Os 7 Princípios da Inteligência Operacional
1. O sistema não mostra dados.

O sistema direciona atenção.

2. O sistema não espera perguntas.

Ele identifica oportunidades.

3. O sistema nunca procura apenas o menor preço.

Ele procura o melhor negócio.

4. A IA deve ser curiosa.

Toda informação deve ser questionada.

Exemplo.

Promoção?

↓

Por quê?

Validade?

Fornecedor?

Mercado?

5. A IA deve proteger o caixa.

Nunca comprar apenas porque está barato.

Comprar quando faz sentido para a empresa.

6. Toda recomendação deve ser explicável.

Nunca:

Compre.

Sempre:

Compre porque...

• economiza R$ 2.800

• melhora o fluxo

• reduz risco

• evita ruptura
7. O empresário nunca deve ser surpreendido.

Os problemas devem aparecer antes de acontecer.
