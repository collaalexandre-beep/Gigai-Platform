Crie um sistema web profissional, escalável e minimalista de ERP + CRM avançado para uma gráfica/comunicação visual.

OBJETIVO GERAL
Quero a base de um sistema que comece pelo cadastro de clientes, contatos e vendedores, mas que já seja arquitetado para evoluir para um ERP completo com orçamento, pedidos, ordem de produção, financeiro, comissões, follow-up comercial, automações e integrações futuras.

O sistema deve ter visual moderno, minimalista, limpo, profissional e muito organizado, com excelente experiência de uso em desktop. O design deve parecer software SaaS moderno, com espaçamento bom, tipografia agradável, poucos excessos visuais, navegação clara e foco em produtividade.

STACK E ARQUITETURA
- Criar aplicação web full-stack.
- Estruturar backend, frontend e banco de dados de forma organizada e escalável.
- O código deve ser limpo, modular e preparado para crescimento.
- Criar autenticação de usuários.
- Criar estrutura para múltiplos módulos no futuro.
- Preparar o banco de dados e a arquitetura para ERP completo.
- Criar APIs internas bem organizadas.
- Criar sistema de logs de erros e ações relevantes.
- Criar validações de dados no frontend e backend.
- Criar estrutura pronta para integrações futuras com:
  - WhatsApp
  - Instagram
  - APIs fiscais
  - consulta de CNPJ
  - emissão de orçamento/pedido
  - financeiro
  - automações por agenda
  - envio de mensagens
  - comissões
  - ordens de produção

IMPORTANTE SOBRE O CNPJ
Quero que o usuário digite SOMENTE o CNPJ e o sistema tente buscar automaticamente os dados da empresa, preenchendo o máximo possível, inclusive:
- razão social
- nome fantasia
- inscrição estadual
- endereço completo
- telefone
- email, se disponível
- situação cadastral
- natureza jurídica
- data de abertura

IMPORTANTE:
- Implementar integração de busca por CNPJ com arquitetura flexível.
- Criar um serviço de consulta de CNPJ desacoplado, para que eu possa trocar a fonte depois.
- Se uma fonte falhar, o sistema deve tentar outra estratégia/fallback.
- Deixar preparado um provider para consulta de dados empresariais.
- Priorizar a captura da Inscrição Estadual, pois isso é muito importante.
- Se algum dado não vier automaticamente, permitir edição manual sem travar o fluxo.
- Exibir claramente quais dados vieram automaticamente e quais foram inseridos manualmente.
- Salvar a data/hora da consulta do CNPJ.
- Criar campo “fonte da consulta”.
- Criar campo “consulta automática bem-sucedida: sim/não”.

OBSERVAÇÃO IMPORTANTE DE PROJETO
Eu sei que algumas fontes de consulta podem ter dificuldade em encontrar dados completos. Estruture o sistema para aceitar uma fonte principal e fontes alternativas de consulta empresarial. Não acople essa lógica diretamente à interface. Quero isso bem organizado no backend.

Cada cliente poderá ter vários contatos.

- Setor

- WhatsApp
- E-mail
- Data de aniversário
- Instagram
- LinkedIn

- Recebe financeiro? (sim/não)
- Recebe produção/status? (sim/não)

Regras importantes:
- Deve ser fácil adicionar, editar e excluir contatos.
- O botão com “+” deve abrir modal ou painel lateral elegante e rápido.
- Deve ser possível marcar um contato como principal.
- Deve ser possível visualizar os contatos em cards ou tabela muito organizada.
- Deve aparecer aniversário próximo dos contatos em destaque no CRM.
- Criar estrutura para futuras automações de relacionamento.

INSTAGRAM / SEGUIR AUTOMATICAMENTE
Quero que o sistema já fique preparado para fluxo de relacionamento via Instagram.
Para cada contato e para cada cliente, deve haver campo de Instagram.

IMPORTANTE:
- Não criar automação acoplada diretamente sem configuração.
- Criar uma estrutura preparada para integração futura com automações.
- Criar no banco campos como:
  - instagram_handle
  - follow_desired (sim/não)
  - follow_status
  - follow_requested_at
  - follow_completed_at
  - follow_error_log
- Criar uma fila/tabela de tarefas de automação para futuras integrações.
- Quando um cliente ou contato novo for cadastrado com Instagram, o sistema deve poder marcar automaticamente uma tarefa pendente de relacionamento, para execução futura.
- Mostrar na interface um status como:
  - pendente
  - em processamento
  - concluído
  - erro
- Não depender da automação para salvar o cadastro.
